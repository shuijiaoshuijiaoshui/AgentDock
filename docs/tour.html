🗺️ AgentDock · 项目导览

AgentDock：企业级 A2A（Agent-to-Agent，代理间协作协议）商家经营智能体中台——一主（编排）七子（域 Agent）+ 人工坐席 + 审计单写者 securityd， LangGraph 编图、a2a-sdk 1.2.3 走协议、智谱 GLM 做理解与合成。当前落地：M1–M4 全量交付（编排 + 七域真实现 + 串行链/上游否决/权威裁决/Saga 补偿 + AgentCard JWS 签发验签 + OTel 跨进程 trace + 多轮历史注入）+ toB 阶段一安全加固（JWT 租户隔离/PII/限流/审批/审计哈希链）+ 人机协同（转人工→接管→回流，工作台三栏）。
