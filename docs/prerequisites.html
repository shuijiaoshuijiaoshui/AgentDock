三句话速览

① 这是一个多 Agent 服务端：客户只对着一个入口说话，编排 Agent 把话路由给各业务域的域 Agent（A2A 协议互相委托），域内用 LangGraph 图 + 工具查库回答；十个进程里还有审计单写者 securityd。
② 确定性优先：AI 只负责"听懂"（意图+槽位）和"说人话"（合成），调谁、什么顺序、何时转人工全部由代码路由表（27 意图）和条件边决定——同一句话永远走同一条链；跨域冲突由纯函数裁决、写链失败由 Saga 补偿。
③ 接不住的时候转人工：结构化交接包（含真实近 6 轮）经同一条 A2A 协议交给人工坐席工作台，坐席在 WebSocket 双向聊天里接管；全程每跳审计哈希链 + OTel 调用树，事后可回放追责。

术语速查（点开可折叠）
术语一句话解释在本项目里对应
A2A（Agent-to-Agent）代理间协作协议：Agent 互相用 HTTP/JSON-RPC 委托任务a2a-sdk 1.2.3；编排↔域、console↔编排、编排↔坐席全走它
AgentCardAgent 的"名片"：名字、能力、skill 列表，挂在 /.well-known/agent-card.json 供发现build_agent_card，10 服务各一张；M4 起随 Card 附 JWS 签名
JWS / ES256（M4）JSON Web Signature；ES256 = ECDSA P-256 非对称签名，验签方只持公钥build_a2a_app 统一签发；delegate 验签通过才建 Task；kid 轮换经 CARD_VERIFY_KEYS_JSON
RFC 8785 JCSJSON 规范化序列化标准，保证签名/验签两侧字节一致SDK signing 模块内部完成，本项目不自研
Task / taskId一次委托的载体，有状态机（submitted→working→completed/input-required…）每次对话一轮 = 新 Task；thread_id = tenant:task_id
contextId会话关联键：多轮、转人工、历史摘全都靠它串== console 的 conversations.id，全系统主键
input-requiredTask 暂停等输入的状态（澄清、二次授权）LangGraph interrupt() 的协议映射
interrupt / resumeLangGraph 的图内暂停与续跑原语澄清、域追问上抛（ask_user）都靠它；暂停态在 checkpointer 里
checkpointer图状态的持久化层，重启后可从断点恢复本机 AsyncSqliteSaver；生产 AsyncPostgresSaver
reducerLangGraph 里"新状态怎么并进旧状态"的函数merge_dict（dict）/ merge_list（list，勿混用！）
权威源矩阵每类事实只有一个域说了算（成交价归订单、实付/到账归财务、ATP 归履约…）orchestrator/arbitrate.py FIELD_AUTHORITY + FACT_AUTHORITY，纯函数查表
Saga 补偿长事务失败时按已完成步骤逆序执行补偿动作cancel_refund：订单取消→财务退款；失败恢复订单，biz_key 幂等
交接包（handoff package）转人工时给坐席的结构化摘要（含 AI 草案、决策日志、近 6 轮历史），不是聊天记录orchestrator handoff 节点组装（graph.py:1246）
会话摘要（M4）更早历史的滚动摘要：近 N 轮原文 + 摘要，控制 token 线性膨胀session_summaries 表；编排生成、渠道层落库、下轮回注
traceparent（M4）W3C Trace Context 的跨进程链路头（version-trace-id-span-id-flags）delegate 注入 metadata/出站头；start_server_span 取远端父上下文
span / 调用树（M4）一次操作的时间区间；父子关系拼成跨服务调用树每服务 span 落 .data/traces/*.jsonl，GET /api/traces 拼树
审计哈希链每条审计带前一条哈希，改/删任一条即断链securityd 单写者；verify_chain 全量校验并定位首条被篡改行
JWT / scope / 租户身份凭证：tenant/actor/role/scopes 全在验签后的 claim 里HTTP Bearer/Cookie + WS 首包认证；SQL 强制 tenant 过滤
PII 脱敏手机/身份证/银行卡/邮箱等敏感信息在进 LLM 前替换mask_pii 三道（入口/落库/历史块）+ llm_guard 键级清洗
桩 Server（stub）占位服务：Card 可发现、调用一律 rejected，绝不假装成功domains/_stub/，参数化起多域
SSE / WebSocket两种服务端实时推送通道；WS 全双工可双向发人工对话用 WS（双向，首包认证），SSE 已退役
OTel（OpenTelemetry）可观测标准：trace/metrics/logs 的 API 与 SDK本阶段只接 trace（span），导出为文件；OTLP 未接
