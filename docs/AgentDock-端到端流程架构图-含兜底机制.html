②跨域一致性与交付兜底 多域数字冲突、快照时点不一致、上游业务否决、产物缺权威来源 按权威矩阵清洗，丢弃值写 decision_log；时点偏差标注；上游否决后下游取消不调用；缺来源整体拒答“来源校验未通过” orchestrator/arbitrate.py · graph.py synthesize / deliver
③域委托兜底（AgentCard JWS） AgentCard 验签失败、kid 未知、域不可达、超时、结构非法 该域 error 占位 = 局部交付，其余域照答；验签失败额外写审计 card.verify_failed；不盲目重发、不编造数据 shared/card_signing.py · shared/a2a_client.py · graph.py domain_call
④写操作门禁与失败兜底 重复提交、误操作、退款（无论金额）、改价/开票超阈值、写链中途失败 退款**无论金额一律人工审批**（阈值只决定 1 人/双人复核）；改价/开票超阈值审批；幂等键判重 + 两阶段确认（一次性 token）；失败不自动重试，按 Saga 逆序补偿，补偿失败升级人工并留痕；已退款订单禁止 restore（防钱货两空） shared/confirmations.py · shared/approvals.py · route_table.py SAGA_CHAINS
⑤权限与数据兜底 跨客户 / 跨租户访问、伪造 action / intent、PII 进入模型、附件越权下载 对象级归属校验（customer=token.sub，staff 显式 customer_id，service 必须 on_behalf_of）；租户复合键；PII 字段脱敏后才进 LLM；附件私有存储 + MIME 嗅探 + 鉴权下载；未注册 action 400、越权 403/404 shared/authz.py · shared/auth.py · shared/llm_guard.py · console/attachments.py

—总原则 任一门禁被拒 / 任一环节失败 写审计；终点只有四种：正常结果、局部交付、拒答、转人工——不存在“悄悄失败”或“伪装成功” shared/audit.py · 全链路

已知缺口（如实标注，不计入兜底承诺）

  • 生产模式 LLM 异常未降级规则分类：真模型超时 / 输出不合 schema 时任务会 failed；只有白名单归一与澄清，未回落 rule_understand（fake 模式本身走规则）。
  • Card 签名密钥在 dev 由全部服务共用一份文件：验签只能证明“本系统签发”，不能证明具体服务身份；生产需每服务独立私钥 + 公钥分发，compose 未挂载密钥。
  • OTel 仅 file exporter + 头部采样：异常全采需 collector 级尾采样；多机部署需共享 TRACE_DIR（compose 未挂卷）。
  • assist 会话历史注入不在本阶段：工作台「AI 查询」已绑定会话客户上下文，但未回注近 6 轮历史/摘要。
