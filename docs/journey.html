🚶 旅程：一条客户消息的一生

从客户在客户页敲下一句话开始，到收到回答（或被转人工）为止，跨 console/编排/域/securityd 的完整时序。 每个节点卡都有 👁 观察点——这一步在哪能亲眼看到（真实日志字符串 / 数据库行 / 页面变化），全部从源码提取。
最后对照代码校验：2026-11-07（防腐 = 改代码后 AI 重读重生成）。

前半程 · AI 应答（主链路）

j0 · 客户发送消息

客户页输入"查询 SKU-A001 的商品详情"。已有会话 → 走 WebSocket（/ws/{cid}，首包 JWT 认证）；首条消息走 REST POST /api/customer/send 建会话。 会话 id = A2A contextId，全链路的关联主键。

👁 观察点：客户页消息立即上屏；localStorage 出现 16 位会话 id；登录后 Cookie 下发（HttpOnly + CSRF 双 Cookie）。

j1 · console 落库并扇出

客户消息 mask_pii 脱敏后写入 messages 表（role=customer），并经 ConvSockets 注册表扇出到该会话所有 WebSocket 连接——工作台若开着这个会话，此刻就能看到。

👁 观察点：sqlite 查 console.db → messages 最新一行 role=customer；工作台聊天窗实时多出这条消息（无需刷新）。

j2 · console → 编排（A2A 委托 + Card 验签）

AI 模式下 console 用 delegate() 以新 Task + 同 contextId 调编排 :8300，请求级 metadata 携带 trace_id / context_id / history（摘要+近 6 轮） / wall_count / 身份。 M4：委托前先拉 /.well-known/agent-card.json → ES256 JWS 验签（验签通过才建 Task，失败审计 card.verify_failed）→ Card 缓存 TTL 300s。同时 console 根 span 激活，traceparent 注入 metadata（跨进程调用树由此扎根）。

👁 观察点：编排侧 a2a_tasks 表新增一行（SUBMITTED→WORKING 流转）；.data/traces/console.jsonl 出现 console.customer_turn span（dev_all 默认开 trace）。

j3 · 编排 intake（脱敏 + 风险 + 装载）

纯代码节点：清洗输入[:2000]、再过一遍 mask_pii、正则检测高风险词（投诉/纠纷/315…）、从请求级 metadata 装载 context_id / wall_count / history、生成 trace_id 与 snapshot_id。身份只认 token claim。

j4 · understand（意图 + 槽位 + 置信，历史注入）

小模型结构化输出 {intent, slots, confidence, top2}（understand@1.5）；历史块（摘要 + 近 6 轮）并入 prompt，每轮再过 mask_pii。 LLM_PROVIDER=fake 时走关键词规则 + 指代槽位继承（"它多少钱"→ 从历史按 sku/order_no/ticket_no 从新到旧补槽）。这是主图里第一处 LLM。

👁 观察点：e2e tests/test_history_injection.py：7 轮后问"它多少钱"仍解析出第 1 轮的 SKU-A002（fake 规则 + 掉窗轮次扫描）。

j4c · 分支：低置信澄清（interrupt）

confidence < 0.6 且 unknown 且未澄清且非高风险 → interrupt()，Task 置 input-required，payload（问题+top2 可点选项）随 status message 下发；console 记 pending_task_id。客户回填后同 taskId 重发 → Command(resume) 从断点续跑——暂停时状态在 checkpointer 里，进程重启仍可续。

👁 观察点：客户页收到澄清问题；重启编排进程后回填仍续跑（AC-14，tests/test_e2e_smoke.py::test_restart_resume_ac14 真杀进程实测）。

j5 · route（查路由表，纯代码）

j6 · advance → domain_call（Send 扇出委托）

advance 拓扑调度器把"无未满足入边"的域用 Send 并发扇出（parallel 单层并行 / serial 逐跳 / arbitrate 分层 DAG）；domain_call 每域一实例转自然语言委托。域追问（单域）→ ask_user 上抛；不可达/验签失败/超时 → 该域 error 占位局部交付；串行链上游否决 → 下游取消。
