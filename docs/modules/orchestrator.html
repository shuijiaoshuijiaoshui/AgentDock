✅ 碰壁计数的跨 Task 通道

每轮对话是新 Task，图状态会重置——碰壁次数存在 console（conversations.wall_count），每轮经请求级 metadata 进图（intake 读），nomatch +1 后经 Artifact 回传 console 落库。M4 的 history 用同一条通道（摘要+近 6 轮随 metadata 进、session_summary 随 artifact 出）——渠道层持会话态、编排层持任务态，边界一致。
